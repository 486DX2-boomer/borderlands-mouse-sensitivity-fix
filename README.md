BL1's lowest possible mouse sensitivity is too high on a modern normal-DPI mouse. This mod adds a second slider that modifies mouse sensitivity, so if you turn your sens all the way down in the game's options and it's still too high, you can further reduce it with the mod slider. It also adds a toggle to disable mouse smoothing, which I'm pretty sure works but it might be placebo, and fixes the X and Y axes so the sensitivity is the same on both, which I'm pretty sure works but that could also be placebo. The sensitivity slider definitely works though!

This is for Borderlands GOTY, the non-enhanced edition.

I recommend using this with the [FOV and sprint rotation fix](https://bl-sdk.github.io/willow1-mod-db/mods/fovandsprintrotationfix/) mod to make the game feel like a proper not-halfassed PC port.

Instructions:

First install the BL1 SDK and then place the MouseSensitivityFix.sdkmod in the sdk_mods folder in the game directory.

"Building":

Zip the MouseSensitivityFix directory and rename the .zip file to .sdkmod.
